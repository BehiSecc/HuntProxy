# HuntProxy v0.4.6

Run `HuntProxy update`. Your data migrates automatically. On a large database the first start takes longer and needs free space of about the database's size.

## Security

- The TCP API rejects DNS rebinding, cross-origin and framed requests, so a page loaded in a HuntProxy browser can no longer read it. Thanks to whiskeykilo (#4).
- `remote_auth_token` is now enforced. From another machine, open the `ui:` link that `HuntProxy status` prints, or send `Authorization: Bearer <token>`. The same machine and SSH tunnels need no token.
- A proxy client on another machine can't reach the API through the proxy.
- `url` 2.5.9 and `cookie` 0.18.3 (RUSTSEC-2026-0592, RUSTSEC-2026-0594).

## New

- **Block rules:** a URL request rule can answer matching requests itself, with a status, content type, body and optional method.
- **Browser actions** apply `timeout_ms`, `wait_ms`, `max_bytes` and `wait_until`, and return any option they did not use in `ignored_options`. `request` can `follow_redirects`.
- **Less output:** `exchange_get` `headers: compact|none` and `history_search` `urls: "short"`.
- **On request:** `reply_send` `response_headers` and `preview_bytes`; `job_status` `wait_ms`.
- **Idle browsers** stop after 30 minutes; `browser_start` resumes them.
- **Faster** proxying and multi-term body searches. A body search stops after 10 s with a partial page you can continue.

## Fixes

- Browser failures say why, and element actions give up after 10 s by default instead of 30 s.
- Tool arguments accept numeric strings such as `"173"` and treat `null` as absent.
- `reply_send`, `reply_send_raw`, `cookies` and `history_search` accept common request mistakes they used to reject.
- `exchange_get` lists a header that repeats with a redacted value once.
- Deleting a project or clearing History no longer stalls captures in other projects.

## Upgrade notes

- **Remote API or UI:** requests from other machines get 401 until they authenticate. Before this release they were not checked.
- **Agents:** `browser_evaluate` returns objects and arrays in `data.value`; a long body search can return `partial: true`.
- **Headed browsers** also stop after 30 idle minutes.
- v0.4.5 can't open the upgraded database. To roll back, restore the update's restore point with the previous executable.
