# HuntProxy v0.4.6

Run `HuntProxy update`. Your data carries over and migrates automatically. The upgrade keeps a copy of the database as its restore point and adds indexes, so the first start takes longer on a large database and needs free space of about the database's size.

If you open the UI or call the API from another machine, read the first note below before updating.

## New

- **Request rules can block:** a URL rule with the Block action answers matching requests itself, with the status, content type and body you set and an optional method, without contacting the origin. Blocked requests are recorded in History with the rule's name. Reply, Fuzzer and extensions are never blocked.
- **Remote access is authenticated:** when the API listens on a non-loopback address, requests from other machines must carry `remote_auth_token`. `HuntProxy status` prints a `ui:` link that signs a browser in once, with nothing to type; scripts send `Authorization: Bearer <token>`. The same machine and SSH tunnels need no token, as before.
- **Idle browsers stop:** a project's browsers stop after 30 minutes without activity. `browser_start` resumes the saved profile.
- **Browser actions apply what they are given:** `timeout_ms`, `wait_ms` (a pause after the action), `max_bytes` (for `snapshot:true`) and `wait_until` (navigate, back, forward). Any option an action does not use comes back in `ignored_options`.
- **`request` can follow redirects** with `follow_redirects`, and says so when a redirect stopped it.
- **`exchange_get` `headers`:** `compact` hides low-signal headers and cuts long values, and `none` omits headers, so more exchanges fit in one call.
- **`history_search`:** a body search stops after 10 s and returns a partial page with a cursor to continue. `urls: "short"` cuts long query strings.
- **`reply_send`** can return response headers (`response_headers`) and a preview of another size (`preview_bytes`).
- **`job_status` can wait** up to 30 s for the job to end (`wait_ms`), instead of being polled.
- **Faster:** responses no longer wait about 40 ms for a delayed ACK, small bodies are captured in memory, memory freed after a burst of traffic is reused, and a body search with several terms decodes each body once.

## Fixes

- **API reachable from web pages:** a page loaded in a HuntProxy browser could read the API through DNS rebinding. The TCP API now rejects a foreign `Host` or `Origin` and cross-site requests. Thanks to whiskeykilo (#4).
- **`remote_auth_token` was never checked:** a non-loopback API required the token in the configuration but accepted every request. It is enforced now, and a proxy client on another machine can no longer reach the API through the proxy.
- **Dependencies:** `url` 2.5.9 and `cookie` 0.18.3 (RUSTSEC-2026-0592, RUSTSEC-2026-0594).
- **Browser failures say why:** nothing matched, an overlay covers the element, the element is disabled, `select` on a custom listbox, or an upload on the wrong element. Element actions give up after 10 s by default instead of 30 s, and one action can no longer outlast the worker and lose the session.
- `pages` without `op` lists pages, `browser_start` with only `cookie_profile` uses it as the profile, and the browser limit error names the sessions that hold the slots.
- `browser_evaluate` returns an object or array as JSON in `data.value`.
- Integer tool arguments may be numeric strings such as `"173"`, and `null` means the argument is absent.
- `reply_send` accepts `identity` and other request fields at the top level, `http1` and `http2` as protocol names, and `body_cleared` together with a bare `body_format`.
- `reply_send_raw` sends a request with bare-LF line endings when it injects managed cookies, and reports that it rewrote them.
- `cookies` set takes `target_url` from a cookie file that names one domain.
- `history_search` accepts a colon before a comparison (`time:>=…`), points header names at `request:~` and `response:~`, and says which term matched nothing.
- `exchange_get` lists a header that repeats with a redacted value once, and a body that fails to decode points to `raw=true`.
- Deleting a project or clearing History no longer stalls captures in other projects.
- A failed IP rotation setup lists the API gateways it could not delete.

## Note

- **Remote UI and API:** if the API listens on a LAN address or a published container port, requests from other machines now get 401 until they authenticate. Run `HuntProxy status` on the machine that runs HuntProxy and open its `ui:` link, or send the Bearer token. Before this release those requests were not checked.
- **Agents:** an element action fails after 10 s unless `timeout_ms` says otherwise. `browser_evaluate` puts objects and arrays in `data.value`; strings stay in `data.content`. A long body search can return `partial: true`; continue with its `next` cursor or narrow the query.
- **Headed browsers:** a browser window you drive by hand also stops after 30 minutes if no tool call or UI action touched its project.
- v0.4.5 can't open the upgraded database. To roll back, restore the update's restore point with the previous executable.
