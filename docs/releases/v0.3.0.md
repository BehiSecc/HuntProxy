# HuntProxy v0.3.0

Run `HuntProxy update`. Your data carries over and migrates automatically. From v0.1.1, run `HuntProxy stop` first, then reconnect your MCP client.

## New

- **Real Chrome browser:** Chromium 153 runs natively, and proxy, Reply and WebSocket traffic use a matching Chrome 153 TLS/HTTP fingerprint.
- **Live per-project upstream proxy:** `projects` action `set_upstream_proxy` takes a proxy URL, `"direct"`, or `null` to use `config.toml`. Changes apply immediately.
- **Quieter History:** Chrome background requests and HuntProxy's own UI traffic are no longer saved.
- **Faster project export.**
- **Plaintext WebSocket interception** and zstd decoding.

## Fixes

- Browser navigation now fails on proxy errors instead of reporting success, and returns the HTTP status.
- Actions on the original page work after a popup opens; back/forward no longer time out.
- The web UI opens on the browser's own project.
- Fixed an occasional hang caused by a SQLite deadlock.
- Clearer errors for browser startup and unknown sessions.

## Note

v0.2.0 can't open the upgraded database. To roll back, restore the update's restore point with the previous executable.
