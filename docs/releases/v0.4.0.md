# HuntProxy v0.4.0

Run `HuntProxy update`. Your data carries over and migrates automatically. From v0.1.x, run `HuntProxy update --version 0.3.0` first.

## New

- **Run JavaScript in the page:** `browser_evaluate` runs code in the selected page or one of its frames, like the DevTools console.
- **Mouse and keyboard:** `browser_input` clicks, hovers, drags and types real keystrokes. Locators take `nth` and `frame`.
- **Browser storage from session files:** a named cookie profile can seed `localStorage` and `sessionStorage` before the first page load.
- **Per-project browsers:** each project has its own browser worker and CDP port, so one stuck project no longer affects the others.
- **Leaner MCP output:** results stay within 24 KB with exact cursors, and `exchange_get` reads bodies inline and up to 20 exchanges at once.
- **Targets with untrusted certificates:** set `verify_upstream_tls = false` in `config.toml` to test self-signed or invalid certificates.

## Fixes

- Reply, raw requests and the crawler now respect the project's rate and concurrency limits, shared with Fuzzer and plugin jobs.
- Console, page error and dialog events include their text.
- `history_search` accepts looser query syntax and adds `query`, `url` and `response` fields.
- Project import is all-or-nothing.
- Updates remove the runtime folders of earlier releases.

## Note

`serve --foreground` and the `BB_*` environment variables were removed. v0.3.0 can't open the upgraded database. To roll back, restore the update's restore point with the previous executable.
